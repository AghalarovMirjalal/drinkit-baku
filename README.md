# Drinkit Baku

Мобильное приложение-лендинг для кофейни Drinkit в Баку. Сделано на React Native (Expo).

## Экраны

- **Главная** — баннер, как работает заказ через умную полку, популярные напитки, бонусы, ближайшая кофейня
- **Меню** — категории, карточка напитка с выбором размера и молока, корзина
- **Кофейни** — схема города, адреса, часы работы, кнопка маршрута

## Запуск

```bash
npm install
npx expo start
```

Дальше открыть в Expo Go на телефоне (QR-код) или нажать `w`, чтобы посмотреть в браузере.

## Стек

- React Native + Expo
- TypeScript
- React Navigation (bottom tabs)
- expo-linear-gradient, @expo/vector-icons
- шрифт Onest

## Ветки

- `main` — стабильная версия
- `develop` — разработка
- `feature/*` — отдельные фичи, мержатся в develop
